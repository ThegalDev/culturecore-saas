# CultureCore SaaS

The advanced AI-driven brand voice architect for the modern enterprise.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Icons**: Lucide React

## Getting Started

This project was generated manually. To run it locally, follow these steps:

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Run Development Server**:
    ```bash
    npm run dev
    ```

3.  **Open Browser**:
    Navigate to [http://localhost:3000](http://localhost:3000).

## Features

- **Voice Architect**: Generate human-readable brand voice guides based on 15+ corporate archetypes.
- **Document Studio**: Rewrite text to match your selected tone (simulated).
- **Premium UI**: "Boardroom-grade" aesthetic with deep navy, gold, and cream colors.
